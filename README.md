# PropData Estonia

Standalone commercial landing page for the Estonia Property & Cadastral API.

## Deploy

Import this repository into Vercel as a static site. No build command or environment variables are required for the landing page.

Recommended production domain: `ee.proptechusa.ai`

The page uses live Stripe subscription checkout links for the Estonia Developer, Builder, and Scale plans. The underlying API remains powered by the shared PropData production infrastructure.
